🔔 GitHub Notification Action Hub

A collection of GitHub Actions that send notifications about GitHub events to Slack, Discord, and Telegram. Add a few lines to your workflow and you are done.

Quickstart¶

  1. Prepare a notification channel — a Slack incoming webhook, a Discord webhook, or a Telegram bot token + chat ID.
  2. Register secrets under Settings → Secrets and variables → Actions in your repository: SLACK_WEBHOOK_URL, DISCORD_WEBHOOK_URL, TELEGRAM_BOT_TOKEN, TELEGRAM_CHAT_ID
  3. Save the snippet below under .github/workflows/ and adjust the uses: path to the action you want.
name: Notify on Issue

on:
  issues:
    types:
      - opened
      - edited
      - reopened

jobs:
  notify:
    runs-on: ubuntu-latest
    steps:
      - name: Send Issue Notification
        id: notify
        uses: developjik/notify-action-hub/notify-on-issue@v1
        with:
          slack_webhook_url: ${{ secrets.SLACK_WEBHOOK_URL }}
          discord_webhook_url: ${{ secrets.DISCORD_WEBHOOK_URL }}
          telegram_bot_token: ${{ secrets.TELEGRAM_BOT_TOKEN }}
          telegram_chat_id: ${{ secrets.TELEGRAM_CHAT_ID }}

The example above uses notify-on-issue. For other events, open the action docs from the matrix above or the cards below.
