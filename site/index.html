🔔 GitHub 알림 액션 허브

GitHub 이벤트에 대한 알림을 Slack, Discord, Telegram으로 전송하는 GitHub Actions 모음입니다. 워크플로우 몇 줄만 추가하면 바로 사용할 수 있습니다.

7개 이벤트 액션 3개 알림 플랫폼 node20 런타임 MIT License

퀵스타트¶

  1. 알림 채널을 준비합니다 — Slack 수신 웹훅, Discord 웹훅, 또는 Telegram 봇 토큰 + 채팅 ID.
  2. GitHub 저장소의 Settings → Secrets and variables → Actions에서 시크릿을 등록합니다: SLACK_WEBHOOK_URL, DISCORD_WEBHOOK_URL, TELEGRAM_BOT_TOKEN, TELEGRAM_CHAT_ID
  3. 아래 예시를 .github/workflows/에 저장하고, uses: 경로를 원하는 액션으로 바꿉니다.
name: 이슈 알림

on:
  issues:
    types: [opened, edited, closed]

jobs:
  notify:
    runs-on: ubuntu-latest
    steps:
      - name: 이슈 알림 보내기
        id: notify
        uses: developjik/notify-action-hub/notify-on-issue@v1
        with:
          slack_webhook_url: ${{ secrets.SLACK_WEBHOOK_URL }}
          discord_webhook_url: ${{ secrets.DISCORD_WEBHOOK_URL }}
          telegram_bot_token: ${{ secrets.TELEGRAM_BOT_TOKEN }}
          telegram_chat_id: ${{ secrets.TELEGRAM_CHAT_ID }}

대표 예시는 notify-on-issue입니다. 다른 이벤트는 위 매트릭스 또는 아래 카드에서 해당 액션 문서를 확인하세요.
