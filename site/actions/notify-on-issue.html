🐞 notify-on-issue

이슈가 열리거나 수정·종료될 때 알림을 보냅니다.

uses: developjik/notify-action-hub/notify-on-issue@v1

위 코드를 복사해 워크플로우의 uses:에 붙여넣으세요.

GitHub 이벤트: issues (opened · edited · closed) Slack · Discord · Telegram

입력값 (Inputs)¶

이름필수기본값설명
slack_webhook_url❌ 선택—Slack 수신 웹훅(Incoming Webhook) URL
discord_webhook_url❌ 선택—Discord 웹훅 URL
telegram_bot_token❌ 선택—Telegram 봇 토큰 (telegram_chat_id와 함께 사용)
telegram_chat_id❌ 선택—Telegram 채팅 ID (telegram_bot_token와 함께 사용)
dry_run❌ 선택false전송 대신 페이로드를 로그로만 출력 (true/false)
message_prefix❌ 선택—알림 메시지 앞에 붙는 접두사 (예: 프로젝트명)

Slack, Discord, Telegram 중 하나 이상의 알림 채널을 설정해야 합니다. 설정하지 않은 플랫폼은 건너뜁니다.

출력값 (Outputs)¶

이름설명
notification_status알림 결과: sent / partial / failed / dry-run / skipped
failed_platforms전송에 실패한 플랫폼의 쉼표 목록 (없으면 빈 문자열)

후속 스텝에서 steps.notify.outputs.* 형태로 참조할 수 있습니다.

사용 예시¶

기본 사용 예시

name: 이슈 알림

on:
  issues:
    types: [opened, edited, closed]

jobs:
  notify:
    runs-on: ubuntu-latest
    steps:
      - name: 이슈 알림 보내기
        id: notify
        uses: developjik/notify-action-hub/notify-on-issue@v1
        with:
          slack_webhook_url: ${{ secrets.SLACK_WEBHOOK_URL }}
          discord_webhook_url: ${{ secrets.DISCORD_WEBHOOK_URL }}
          telegram_bot_token: ${{ secrets.TELEGRAM_BOT_TOKEN }}
          telegram_chat_id: ${{ secrets.TELEGRAM_CHAT_ID }}

출력값 사용 예시

- name: 알림 결과 확인
  if: ${{ steps.notify.outputs.notification_status == 'partial' }}
  run: echo "실패한 플랫폼 = ${{ steps.notify.outputs.failed_platforms }}"
